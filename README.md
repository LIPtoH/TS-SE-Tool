# TS SET
Truck Simulator Save Editor Tool

## Community compatibility build

This repository contains compatibility fixes and maintenance for newer versions of Euro Truck Simulator 2 and American Truck Simulator.

**Original project:** [LIPtoH/TS-SE-Tool](https://github.com/LIPtoH/TS-SE-Tool)  
**Compatibility fixes & maintenance:** [rusplane](https://rusplane.dev)

### Current compatibility work

This build includes updates required for newer ETS2 / ATS save formats, including compatibility fixes for game version **1.61**.

The original application, design and core functionality were created by **LIPtoH**. The newer compatibility work is maintained by **rusplane**.

## Description
Small tool for editing save files of Euro Truck Simulator 2 and American Truck Simulator.

## OS
Windows x64

### Dependence
.NET Framework 4.7.2

## You can:
* add Custom paths for save files.
* edit Local and Steam save files.
* edit Player level and skill.
* edit and share saved User Colors for truck and trailer.
* edit amount of Money on account.
* visit Cities and be able to grab cargo from discovered cities.
* buy and\or upgrade Garages.
* repair and\or refuel your Truck.
* Share truck paint job.
* repair Trailer.
* create custom jobs for Freight market.
* make basic edits to Cargo market.
* share Truck position.
* share GPS paths.
* share Multiple Truck positions as one Convoy Control pack.

## Short term goals:
* finish sharing functions for truck parts.
